# Анастасия и Богдан — handoff приглашения

## Источники

- Актуальный интерактивный макет: `dist/index.html`
- Все используемые изображения и шрифты: `dist/assets/`
- Экран рассчитан прежде всего на мобильную ширину `430px`; на широком экране приглашение остаётся колонкой шириной `430px` по центру.
- Форма в текущем HTML демонстрационная: данные никуда не отправляются.

```css
--ink: #282324;

--berry: #760d1b;
--blue: #e4eff4;
--line: rgba(40, 35, 36, .18);
--accent-font: "Bad Script", cursive;

```

- Основной межбуквенный интервал: `1.2px`.
- Акцентный шрифт: `Bad Script`; информационный: `Neucha`.
- Заголовки секций: `52px`, Bad Script, бордовые.
- Информационный текст и поля: `18px/24px`, Neucha.
- Поля формы: высота `52px`, радиус `14px`, нейтральная обводка.
- RSVP-блок: пастельно-голубой фон `#e4eff4`.
- Использовать исходные PNG без перерисовки. Главная иллюстрация повёрнута CSS-трансформацией, сам файл не поворачивать.

## Контракт RSVP

Предлагаемый запрос: `POST /api/rsvp`, JSON, схема лежит в `rsvp.schema.json`.

Пример:

```json
{
  "name": "Анна и Иван",
  "attendance": "yes",
  "song": "ABBA — Dancing Queen",
  "drinks": ["sparkling", "white_wine"]
}
```

Успех: `201 Created` и `{ "ok": true, "id": "..." }`.

Ошибки валидации: `400` и `{ "ok": false, "errors": { "name": "..." } }`.

Защитить endpoint от спама: rate limit, honeypot или Turnstile. Не хранить лишние персональные данные. Для гостей полезно показать успешное состояние формы и не позволять двойную отправку во время запроса.

## Что должен реализовать следующий чат

1. Выбрать стек фронтенда и бэкенда, сохранив визуальный результат `dist/index.html` пиксель-в-пиксель.
2. Подключить `POST /api/rsvp` к форме вместо демонстрационного toast.
3. Добавить серверную валидацию по `rsvp.schema.json`.
4. Выбрать хранилище RSVP (таблица/БД) и способ просмотра ответов организаторами.
5. Добавить состояния `loading`, `success`, `validation error`, `server error`.
6. Проверить мобильные ширины 320–430px, клавиатурную навигацию и контраст.
7. Сохранить точные тексты, порядок блоков, цвета, изображения и два шрифта.
