# Свадебное приглашение Анастасии и Богдана

Адаптивное онлайн-приглашение на 6 февраля 2027 года. Визуальная часть перенесена из утверждённого макета без замены иллюстраций и шрифтов.

## Что внутри

- статический mobile-first фронтенд в `public/`;
- `POST /api/rsvp` с клиентской и серверной валидацией;
- хранение ответов в бесплатном проекте Supabase;
- защита от двойной отправки, honeypot и лимит 5 ответов за 10 минут с одного хеша IP;
- защищённая CSV-выгрузка по адресу `/api/rsvp/export.csv`;
- конфигурация деплоя на Vercel.

## Локальная проверка

Нужен Node.js 20 или новее.

```bash
npm run check
npm run preview
```

Страница откроется на `http://127.0.0.1:4173`. В простом локальном preview API не запускается; серверная логика проверяется тестами. Полную связку фронтенда и API можно проверить через `vercel dev` после настройки переменных окружения.

## Настройка базы

1. Создайте бесплатный проект в Supabase.
2. Откройте SQL Editor и выполните файл [`supabase/schema.sql`](supabase/schema.sql).
3. Скопируйте Project URL и `service_role` key из настроек API. Сервисный ключ используется только на сервере и не попадает в браузер.

Таблица защищена RLS без публичных политик: читать и записывать ответы может только серверная функция с сервисным ключом.

## Деплой

1. Импортируйте этот GitHub-репозиторий в Vercel.
2. Добавьте переменные окружения из `.env.example`:
   - `SUPABASE_URL`;
   - `SUPABASE_SERVICE_ROLE_KEY`;
   - `IP_HASH_SALT` — длинная случайная строка;
   - `ADMIN_EXPORT_TOKEN` — пароль для CSV-выгрузки.
3. Запустите deployment. Vercel автоматически отдаст файлы из `public/` и функции из `api/`.

Форма отправляет JSON на тот же домен по `POST /api/rsvp`, поэтому отдельные CORS-настройки не нужны.

## Просмотр ответов

Ответы видны в Supabase: `Table Editor → rsvps`. Оттуда их можно экспортировать стандартными средствами Supabase.

Для быстрой CSV-выгрузки откройте:

```text
https://ваш-домен/api/rsvp/export.csv
```

Браузер запросит логин и пароль. Логин можно указать любой, пароль — значение `ADMIN_EXPORT_TOKEN`.

## Контракт API

```json
{
  "name": "Анна и Иван",
  "attendance": "yes",
  "song": "ABBA — Dancing Queen",
  "drinks": ["sparkling", "white_wine"]
}
```

Успех: `201 Created` и `{ "ok": true, "id": "..." }`. Повтор запроса с тем же `Idempotency-Key` безопасно вернёт существующий ответ.

Схема запроса находится в [`rsvp.schema.json`](rsvp.schema.json).
